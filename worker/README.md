# تفعيل السعر اللحظي (اختياري)

التطبيق يعمل **مجاناً وبلا أي إعداد** — مهمة GitHub Actions تحدّث البيانات كل 10 دقائق.
هذا الملف لمن أراد أسعاراً لحظية عبر اشتراك مدفوع.

## لماذا وسيط؟ لماذا لا نضع المفتاح في الصفحة؟

لأن أي زائر يستطيع فتح كود الصفحة ونسخ مفتاحك، ثم يستنفد باقتك فيتوقف تطبيقك.
الـ Worker يحمل المفتاح بعيداً عن المتصفح، ويخزّن النتيجة 5 ثوانٍ —
فمهما زاد عدد الزوار يبقى استهلاكك طلباً واحداً كل 5 ثوانٍ.

الباقة المجانية من Cloudflare تكفي تماماً: **100,000 طلب يومياً**.

---

## الخطوات (10 دقائق، مرة واحدة)

### 1) اشترك عند مزوّد بيانات

| المزوّد | ملاحظات |
|---|---|
| **Financial Modeling Prep** | الأنسب — مفتاح واحد يغطي الأسعار والبيانات الأساسية والأخبار، وفيه طلب دفعة واحدة لكل الرموز |
| **Twelve Data** | أسعار ممتازة وموثوقية عالية، لكن الأساسيات والأخبار أضعف |

> الأسعار تتغيّر باستمرار — راجع صفحة الأسعار عند المزوّد قبل الدفع،
> وتأكد أن الباقة تشمل **الأسعار اللحظية للأسهم الأمريكية** لا المؤجّلة 15 دقيقة.

### 2) أنشئ الـ Worker

1. افتح [dash.cloudflare.com](https://dash.cloudflare.com) وسجّل حساباً مجانياً.
2. من القائمة: **Workers & Pages** ← **Create** ← **Create Worker**.
3. سمِّه مثلاً `stocks-live` ثم **Deploy**.
4. اضغط **Edit code**، امسح الكود الموجود، والصق محتوى `worker.js` كاملاً، ثم **Deploy**.

### 3) أضف المتغيّرات السرّية

من صفحة الـ Worker: **Settings** ← **Variables and Secrets** ← **Add**:

| الاسم | النوع | القيمة |
|---|---|---|
| `API_KEY` | Secret | مفتاحك من المزوّد |
| `PROVIDER` | Text | `fmp` أو `twelvedata` |
| `ALLOW` | Text | `https://alkongrs2014.github.io` |

> `ALLOW` مهم: بدونه يستطيع أي موقع استخدام وسيطك ويستنفد باقتك.

اضغط **Deploy** بعد الإضافة.

### 4) اربطه بالتطبيق

افتح `stocks/config.js` في المستودع وضع رابط الـ Worker:

```js
LIVE_ENDPOINT: "https://stocks-live.اسم-حسابك.workers.dev",
```

احفظ وادفع التغيير. خلال دقيقة سيعرض الشريط العلوي **«لحظي»** بدل **«من الملفات»**.

## التحقق

افتح في المتصفح:

```
https://stocks-live.اسم-حسابك.workers.dev/?symbols=AAPL,MSFT
```

الرد الصحيح:

```json
{ "updated": 1767225600000, "provider": "fmp", "count": 2,
  "quotes": { "AAPL": { "price": 231.4, "chg": 0.82, ... } } }
```

| المشكلة | السبب |
|---|---|
| `API_KEY غير مضبوط` | لم تُضِف المتغيّر السرّي أو لم تضغط Deploy بعده |
| `origin not allowed` | قيمة `ALLOW` لا تطابق نطاقك بالضبط (بلا `/` في آخره) |
| `502` مع رسالة من المزوّد | المفتاح خاطئ أو الباقة لا تشمل الأسهم اللحظية |

## الأمان والتكلفة

- المفتاح لا يظهر في المتصفح إطلاقاً — يبقى داخل Cloudflare.
- التخزين 5 ثوانٍ يعني أن 100 زائر متزامن = طلب واحد للمزوّد.
- الـ Worker يُستدعى فقط **أثناء فتح السوق** — التطبيق لا يسحب أسعاراً والسوق مغلق.
- عند أي خطأ في الوسيط يرجع التطبيق تلقائياً لبيانات الملفات المجانية، فلا ينقطع.

## للرجوع للوضع المجاني

اجعل `LIVE_ENDPOINT` نصاً فارغاً في `config.js`. لا شيء آخر يتغيّر.
