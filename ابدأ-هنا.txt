webtrade — مرصد الأسهم الأمريكية (تشغيل محلي)

الخطوات:
  1. ثبّت Node.js من nodejs.org  (النسخة LTS)
  2. ثبّت Git من git-scm.com
  3. شغّل   local\start.bat  ... إلخ (انظر الجدول)
  4. انسخ  .env.example  باسم  .env  وضع مفتاح Finnhub فيه

الاختصارات في مجلد local — لكل واحد اسمان (عربي وإنجليزي) ونفس العمل.
استخدم الإنجليزي لو ظهرت رموز غريبة في نافذة الأوامر:

  update-all.bat   /  تحديث-كامل.bat      جلب كل البيانات (ابدأ بهذا)
  start.bat        /  تشغيل-الموقع.bat     فتح الموقع على localhost:8080
  update.bat       /  تحديث-الاسعار.bat    تحديث الأسعار والشمعات
  quotes.bat       /  تحديث-سريع.bat        أسعار فقط (~90 ثانية) وينشرها
  schedule.bat     /  جدولة-تلقائية.bat    تحديث تلقائي كل 10 دقائق
  link-github.bat  /  ربط-بجيت-هب.bat      ربط المجلد بمستودع GitHub
  publish.bat      /  نشر-البيانات.bat      نشر بيانات جهازك للموقع المنشور
  schedule-publish.bat / جدولة-مع-النشر.bat  جدولة تلقائية تنشر بعد كل تحديث
