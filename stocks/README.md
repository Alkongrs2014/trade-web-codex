# مرصد الأسهم الأمريكية

تطبيق ويب عربي لمتابعة **أكبر 70 شركة أمريكية بالقيمة السوقية**:
قراءة فنية على أربعة فريمات زمنية، بيانات الشركة الأساسية، مستويات الدعم والمقاومة،
حاسبة حجم الصفقة، تنبيهات سعرية، وأخبار — كل ذلك مجاناً وبلا مفتاح API.

## كيف يعمل

```
المتصفح (GitHub Pages)          GitHub Actions (كل 10 د)        Yahoo Finance
  stocks/index.html  ──يقرأ──▶  فرع data (ملفات JSON)  ◀──يكتب──  (من طرف الخادم)
```

لا يوجد مصدر مجاني للأسهم الأمريكية يسمح للمتصفح بالاتصال به مباشرة (بعكس العملات الرقمية).
لذلك تجلب مهمة مجدولة البيانات من طرف الخادم وتحفظها كملفات JSON يقرأها التطبيق:
مجاني تماماً، بلا مفتاح، وبلا مشاكل CORS. الثمن الوحيد أن البيانات متأخرة نحو 15 دقيقة.

## التشغيل لأول مرة

1. **فعّل GitHub Pages**: `Settings` ← `Pages` ← المصدر `main` والمجلد `/ (root)`.
   الرابط سيكون `https://alkongrs2014.github.io/stocks/`.
2. **شغّل المهمة اليومية يدوياً**: تبويب `Actions` ← `البيانات اليومية` ← `Run workflow`.
   هذه تبني ترتيب الـ70 والبيانات الأساسية.
3. **شغّل مهمة السوق يدوياً**: `Actions` ← `تحديث بيانات السوق` ← `Run workflow`.
   هذه تنشئ فرع `data` وتملؤه بالأسعار والشموع.
4. افتح الرابط. بعدها تعمل المهمتان تلقائياً بلا تدخّل.

## الملفات

| الملف | الدور |
|---|---|
| `stocks/index.html` | التطبيق كاملاً — بلا مكتبات خارجية |
| `stocks/config.js` | الإعدادات الوحيدة التي تُعدَّل يدوياً |
| `stocks/symbols.json` | كون البحث (90 رمزاً) — المهمة اليومية تختار منها أعلى 70 |
| `scripts/fetch-market.mjs` | الأسعار والشموع والمؤشرات (كل 10 دقائق) |
| `scripts/fetch-daily.mjs` | الترتيب والأساسيات والأخبار (يومياً) |
| `worker/` | وسيط اختياري للسعر اللحظي — انظر `worker/README.md` |

## اختبار الكود

```bash
node scripts/fetch-market.mjs --check    # فحص ذاتي بلا شبكة
node scripts/fetch-daily.mjs  --check
```

## ملاحظات تشغيلية

- **فرع `data` منفصل عمداً**: المهمة تكتب ~130 مرة أسبوعياً، ولو كتبت على `main`
  لأغرقت سجل مساهماتك في GitHub. الفرع يُحفظ ككوميت واحد دائماً فلا يتضخّم المستودع.
- **GitHub يوقف المهام المجدولة بعد 60 يوماً من خمول المستودع** — أعِد تشغيلها
  بضغطة `Run workflow` من تبويب Actions.
- **تعديل قائمة الشركات**: عدّل `stocks/symbols.json`. المهمة اليومية ترتّب حسب
  القيمة السوقية الفعلية وتختار أعلى `top`.

## تنبيه

أداة معلوماتية وتعليمية فقط. ليست توصية بيع أو شراء ولا نصيحة استثمارية.
البيانات من مصادر عامة مجانية وقد تتأخر أو تنقطع.
