# webtrade — التشغيل المحلي على ويندوز

## لماذا محلياً أفضل من GitHub؟

المشكلة ليست في الكود بل في **عنوان الشبكة**:

| | على GitHub Actions | على جهازك |
|---|---|---|
| Yahoo Finance | ⛔ يرفض كل طلب بـ `429` | ✅ يعمل — غير محظور |
| الشموع | محدودة بـ 800 طلب/يوم (Twelve Data) | **بلا سقف** |
| سرعة التعبئة | 14 رمزاً كل تشغيل ← ساعة كاملة | **الـ70 دفعة واحدة** |
| الجدولة | متقطّعة | Task Scheduler موثوق |
| الأسعار اللحظية | Finnhub | Finnhub (نفس الشيء) |

مزوّدو بيانات الأسهم يحظرون نطاقات مزوّدي السحابة لأنها مصدر الاستخراج
الآلي. شبكتك المنزلية ليست كذلك — وهذا وحده يحلّ أكبر عقبتين واجهتا
المشروع.

### وهذا يفيد الموقع المنشور أيضاً، لا نسختك وحدها

مهام GitHub كانت تنتج بيانات **ناقصة لا معطّلة**: السعر يصل لأن Finnhub
يعمل من السحابة، والشموع لا تصل. فيظهر الموقع المنشور بسعر اليوم وشارت
ومؤشرات مبنية على شمعات عمرها أيام — وهو أسوأ من غياب البيانات لأنه لا
يبدو خطأً.

`نشر-البيانات.bat` يدفع بيانات جهازك إلى فرع `data` الذي يقرأه الموقع
المنشور، فيصير بجودة نسختك المحلية. وبوابة السلامة نفسها التي في مهمة
GitHub تعمل هنا: لا يُنشر شيء إن لم تمرّ البيانات الفحص.

## التثبيت (مرة واحدة)

### 1) ثبّت Node.js
حمّل النسخة LTS من <https://nodejs.org> وثبّتها بالخيارات الافتراضية.
للتأكد، افتح موجّه الأوامر واكتب:
```
node -v
```
يجب أن يظهر رقم إصدار مثل `v20.x` أو أحدث.

### 2) ضع مفتاح Finnhub
انسخ الملف `.env.example` باسم `.env` ثم افتحه بالمفكرة وضع مفتاحك:
```
FINNHUB_API_KEY=مفتاحك_هنا
PREFER_YAHOO=1
```

> مفتاح Finnhub مجاني من <https://finnhub.io/dashboard> (بريد فقط، بلا بطاقة).
> **بدونه يعمل الموقع أيضاً** — لكن الأسعار تأتي من إغلاق آخر شمعة بدل
> السعر اللحظي.
>
> `TWELVEDATA_API_KEY` **غير مطلوب محلياً** — يبقى احتياطاً فقط لو تعطّل
> Yahoo يوماً.

## الاستخدام اليومي

انقر نقراً مزدوجاً على الملفات في مجلد `local`:

| الملف | ماذا يفعل |
|---|---|
| **`تحديث-كامل.bat`** | يجلب كل شيء (شغّله أول مرة — يستغرق دقائق) |
| **`تشغيل-الموقع.bat`** | يفتح الموقع في المتصفح على `localhost:8080` |
| **`تحديث-الاسعار.bat`** | تحديث الأسعار والشمعات والأخبار |
| **`تحديث-سريع.bat`** | أسعار فقط (~90 ثانية) ثم ينشرها |
| **`جدولة-تلقائية.bat`** | يجعل التحديث يعمل تلقائياً بلا تدخّل |
| **`نشر-البيانات.bat`** | يدفع بيانات جهازك للموقع المنشور على GitHub |
| **`جدولة-مع-النشر.bat`** | جدولة تلقائية **تنشر** بعد كل تحديث |

### أول مرة — بالترتيب
1. `تحديث-كامل.bat` — انتظر حتى ينتهي
2. `تشغيل-الموقع.bat` — يفتح المتصفح تلقائياً
3. `جدولة-مع-النشر.bat` — يُنشئ الدورات الثلاث ويدفع كل تحديث إلى
   الموقع المنشور (يتطلب `ربط-بجيت-هب.bat` أولاً).
   أو `جدولة-تلقائية.bat` إن أردت التحديث المحلي وحده بلا نشر.

> الجدولة تعمل فقط والجهاز يعمل. لإلغائها:
> ```
> schtasks /Delete /TN "WebTrade-Quotes" /F
> schtasks /Delete /TN "WebTrade-Market" /F
> schtasks /Delete /TN "WebTrade-Options" /F
> schtasks /Delete /TN "WebTrade-Daily" /F
> ```

> **لماذا `run-hidden.vbs`؟** المهام لا تنادي `node` مباشرة، بل
> `wscript.exe local\run-hidden.vbs`. السبب أن `node` تطبيق كونسول،
> فيفتح Windows نافذة طرفية مرئية عند كل تشغيل — أي كل دقيقتين مع دورة
> الأسعار، وهو إزعاج متواصل. الوسيط يشغّل الأمر نفسه بنافذة مخفية.
> لمتابعة ما يجري، شغّل `node local\run.mjs quotes` يدوياً في طرفية.
>
> والوسيط **ينتظر** node ولا يعود فوراً. لو عاد فوراً لظنّ المجدول أن
> المهمة انتهت بنجاح قبل أن يبدأ العمل، فتتعطّل ثلاث حمايات دفعةً واحدة:
> السقف الزمني لا يقتل تشغيلاً عالقاً أبداً، ونتيجة آخر تشغيل تقول
> «نجح» دائماً، ومنع التداخل لا يرى تداخلاً قط.

> **لماذا `schedule.ps1` لا ملف `.bat`؟** `cmd.exe` يتتبّع موضعه في ملف
> الدفعة بالبايتات؛ ومع `chcp 65001` ونص عربي طويل يختلّ التتبّع فتُقرأ
> أوامر `schtasks` مقطّعةً — وينتهي الأمر بمهام بعضها أُنشئ وبعضها لا،
> بلا رسالة خطأ واضحة. ملفات `.bat` هنا صارت أسطراً إنجليزية قليلة
> تستدعي `schedule.ps1`، وفيه المنطق والنص العربي معاً.
> (وهو محفوظ بـUTF-8 **مع BOM**: بدونها تقرأه PowerShell 5.1 كـANSI
> فيتشوّه العربي وينهار التحليل.)

## من سطر الأوامر

```bat
node local\run.mjs quotes    :: أسعار فقط — الحلقة السريعة
node local\run.mjs market    :: شمعات ومؤشرات + أخبار
node local\run.mjs news      :: أخبار وحدها
node local\run.mjs daily     :: أساسيات وترتيب الشركات
node local\run.mjs both      :: كل شيء
node local\run.mjs serve     :: الخادم المحلي
node local\run.mjs publish   :: نشر البيانات على فرع data
```

### لماذا ثلاث دورات لا واحدة

ما يتغيّر كل دقيقة هو **السعر**، لا الشمعة المكتملة ولا أرقام الشركة:

| المهمة | الدورة | ما تجلبه |
|---|---|---|
| `quotes` | دقيقتان | الأسعار ونسب التغيّر والقطاعات |
| `market` | 10 دقائق | الشمعات والمؤشرات الفنية والأخبار |
| `daily` | يومياً | الأساسيات وترتيب أكبر 70 |

**ولماذا دقيقتان لا دقيقة؟** المزوّد المجاني يسمح بستين طلباً في
الدقيقة، وكل سهم طلب مستقل، فسبعون سهماً تحتاج ~90 ثانية لدورة كاملة.
الحد عدد الطلبات لا سرعة الشبكة، ولا يُتجاوز إلا باشتراك مدفوع.

أضف `--publish` لأي أمر جلب فينشر بعده، وبشرط نجاح الجلب:

```bat
node local\run.mjs market --publish
```

## أين البيانات؟

في مجلد `data\` بجانب المشروع:

```
data\summary.json        صف لكل سهم (سعر، تغيّر، نتيجة فنية)
data\market.json         مزاج السوق والمؤشرات والقطاعات
data\sym\AAPL.json       شموع ومؤشرات كل سهم
data\fundamentals.json   أساسيات الشركات
data\news.json           الأخبار
data\meta.json           إحصاءات آخر تشغيل — راجعه عند أي مشكلة
```

الصفحة تكتشف مكانها تلقائياً: على `localhost` تقرأ من `data\` المحلي،
وإن نُشرت على الويب تقرأ من فرع `data` في GitHub. **ملف إعدادات واحد
يعمل في الحالتين.**

## حل المشكلات

**«node غير معروف كأمر»** — Node.js غير مثبّت أو يحتاج إعادة فتح موجّه
الأوامر بعد التثبيت.

**الأسعار لا تظهر** — افتح `data\meta.json` وانظر `marketRun`:
- `finnhub.failures` مرتفع ← تحقّق من المفتاح في `.env`
- `sources.chart.fail` مرتفع ← Yahoo يرفض؛ نادر منزلياً، جرّب لاحقاً

**الصفحة فارغة** — شغّل `تحديث-كامل.bat` أولاً؛ لا بيانات = لا عرض.

**«لم ينجح أي رمز»** — هذا حماية مقصودة: لا يُكتب فوق بيانات سليمة
ببيانات فاشلة. تحقّق من الإنترنت وأعد المحاولة.

## هل ما زلت تريد الموقع منشوراً على الإنترنت؟

يمكن الجمع: جهازك يجلب البيانات (بلا حظر) ثم يدفعها إلى فرع `data`،
وGitHub Pages يخدم الصفحة للعالم. أضف بعد التحديث:

```bat
cd /d D:\Ai\ClaudeCode\trade\webtrade
git add data && git commit -m "بيانات" && git push origin main
```

عندها تحصل على الأفضلين: جلب بلا حظر، ونشر عام مجاني.
